# IT Repair Desk

ระบบแจ้งซ่อมแบบ Static Web สำหรับใช้งานภายในหน่วยงานเดียว โดยใช้ Supabase เป็นฐานข้อมูลและมีโหมดแอดมินแบบรหัสผ่านช่องเดียว

## การเข้าโหมดแอดมิน

1. กด `เข้าสู่ระบบแอดมิน`
2. กรอกรหัสผ่าน `36335`
3. สถานะล็อกอินจะอยู่เฉพาะในแท็บเบราว์เซอร์ปัจจุบัน และถูกล้างเมื่อปิดแท็บ

ระบบนี้ทำงานบน GitHub Pages จึงไม่สามารถเก็บรหัสผ่านที่เขียนใน JavaScript เป็นความลับได้ โหมดนี้ควรใช้เป็นตัวกั้นหน้าจอสำหรับระบบภายในความเสี่ยงต่ำเท่านั้น ผู้ที่เปิดดู `script.js` จะสามารถเห็นรหัสผ่านและเรียก Supabase API ด้วย publishable key ได้

## การป้องกันที่เพิ่มไว้

- Escape ข้อมูลก่อนแสดงใน HTML เพื่อลดความเสี่ยง Stored XSS
- ไม่สร้าง event handler จากข้อความที่ผู้ใช้กรอก
- อนุญาตรูปเฉพาะ JPG, PNG และ WebP ขนาดไม่เกิน 5 MB
- ตรวจสถานะแอดมินก่อนเปิดคำสั่งจัดการจากหน้าเว็บ
- ไม่ใส่ `service_role` key ใน repository

## รายงานประจำปี

ในหน้า `ภาพรวมแอดมิน` สามารถเลือกปีเพื่อดูสรุปจำนวนใบงาน สถานะ อัตราปิดงาน งานเร่งด่วน กราฟ และตารางแยกตามเดือน จากนั้นกด `พิมพ์รายงาน` เพื่อพิมพ์หรือบันทึกเป็น PDF ในรูปแบบกระดาษ A4 แนวนอนได้

## Supabase

ไฟล์ `supabase-security.sql` เป็นคำอธิบายข้อจำกัดของโหมดรหัสผ่านอย่างเดียว และไม่จำเป็นต้องรัน หากต้องการความปลอดภัยระดับฐานข้อมูลในอนาคต ต้องเปลี่ยนไปใช้ Supabase Auth หรือ backend ที่ตรวจสอบตัวตนได้

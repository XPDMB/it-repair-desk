# IT Repair Desk

ระบบแจ้งซ่อมแบบ Static Web สำหรับใช้งานภายในหน่วยงานเดียว โดยใช้ Supabase เป็นฐานข้อมูลและมีโหมดแอดมินแบบรหัสผ่านช่องเดียว

## การเข้าโหมดแอดมิน

1. กด `เข้าสู่ระบบแอดมิน`
2. กรอกรหัสผ่าน `36335`
3. สถานะล็อกอินจะอยู่เฉพาะในแท็บเบราว์เซอร์ปัจจุบัน และถูกล้างเมื่อปิดแท็บ

ระบบนี้ทำงานบน GitHub Pages จึงไม่สามารถเก็บรหัสผ่านที่เขียนใน JavaScript เป็นความลับได้ โหมดนี้ควรใช้เป็นตัวกั้นหน้าจอสำหรับระบบภายในความเสี่ยงต่ำเท่านั้น ผู้ที่เปิดดู `script.js` จะสามารถเห็นรหัสผ่านและเรียก Supabase API ด้วย publishable key ได้

## เมนูบริการและใบลงทะเบียนอินเทอร์เน็ต

หน้าผู้ใช้เริ่มต้นด้วยเมนูบริการ 2 รายการ คือ `แจ้งซ่อมอุปกรณ์` และ `ลงทะเบียนอินเทอร์เน็ต` โดยแยกขั้นตอนการทำงานออกจากกันอย่างชัดเจน

ใบลงทะเบียนอินเทอร์เน็ตรองรับข้อมูลหนังสือ ข้อมูลผู้ขอ อุปกรณ์ MAC Address พื้นที่ใช้งาน คำรับรองตาม พ.ร.บ.คอมพิวเตอร์ และจัดหน้าเอกสาร A4 แนวตั้งสำหรับพิมพ์หรือบันทึกเป็น PDF ข้อมูลจะบันทึกเป็นร่างเฉพาะใน LocalStorage ของเบราว์เซอร์เครื่องที่กรอก และไม่ส่งขึ้น Supabase

## การป้องกันที่เพิ่มไว้

- Escape ข้อมูลก่อนแสดงใน HTML เพื่อลดความเสี่ยง Stored XSS
- ไม่สร้าง event handler จากข้อความที่ผู้ใช้กรอก
- อนุญาตรูปเฉพาะ JPG, PNG และ WebP ขนาดไม่เกิน 5 MB
- ตรวจสถานะแอดมินก่อนเปิดคำสั่งจัดการจากหน้าเว็บ
- ไม่ใส่ `service_role` key ใน repository

## รายงานประจำปี

ในหน้า `ภาพรวมแอดมิน` สามารถเลือกปีเพื่อดูสรุปจำนวนใบงาน สถานะ อัตราปิดงาน งานเร่งด่วน กราฟ และตารางแยกตามเดือน จากนั้นกด `พิมพ์รายงาน` เพื่อพิมพ์หรือบันทึกเป็น PDF ในรูปแบบกระดาษ A4 แนวนอนได้

## การปรับความเร็ว

- หน้าแรกโหลดเฉพาะข้อมูลข้อความของใบงาน ไม่ดึงรูปภาพทั้งหมดจากฐานข้อมูลพร้อมกัน
- รูปก่อนซ่อมและรูปหลังซ่อมจะโหลดเมื่อกด `ดูรูป` ของรายการนั้นเท่านั้น
- รูปใหม่จะถูกย่อให้ด้านยาวไม่เกิน 1,600 พิกเซลและแปลงเป็น WebP เมื่อช่วยลดขนาดไฟล์ได้
- Chart.js จะโหลดเฉพาะตอนแอดมินเปิดหน้า `ภาพรวมแอดมิน`
- หน้าเว็บแสดงข้อมูลสำรองจาก LocalStorage ก่อน แล้วจึงอัปเดตข้อมูลล่าสุดจาก Supabase เบื้องหลัง

## การใช้งานบนโทรศัพท์

หน้าเว็บปรับรูปแบบอัตโนมัติตามความกว้างหน้าจอ รองรับมือถือ Android และ iPhone รวมถึงหน้าจอขนาดเล็ก 320 พิกเซล เมนู ปุ่ม การ์ด แบบฟอร์ม และหน้าต่างดูรูปมีพื้นที่สัมผัสที่เหมาะสม ส่วนตารางรายงานประจำปีสามารถเลื่อนในแนวนอนได้โดยไม่ทำให้ทั้งหน้าเว็บล้นออกนอกจอ

## รูปแบบหน้าจอ

ใช้ธีม Modern Professional โทนม่วง–น้ำเงิน พื้นหลังไล่สีแบบอ่อน การ์ดมีมิติและแบ่งลำดับข้อมูลชัดเจน พร้อมสถานะสีสำหรับงานรอรับเรื่อง กำลังซ่อม เสร็จแล้ว และงานเร่งด่วน โดยคงรูปแบบที่อ่านง่ายทั้งบนคอมพิวเตอร์และโทรศัพท์

## Supabase

ไฟล์ `supabase-security.sql` เป็นคำอธิบายข้อจำกัดของโหมดรหัสผ่านอย่างเดียว และไม่จำเป็นต้องรัน หากต้องการความปลอดภัยระดับฐานข้อมูลในอนาคต ต้องเปลี่ยนไปใช้ Supabase Auth หรือ backend ที่ตรวจสอบตัวตนได้
